# Care Connect

## 📖 Overview

Care Connect is a web-based platform developed to support orphanages and elderly homes by connecting them with donors and volunteers. The platform provides an easy way for users to explore beneficiary profiles, understand their needs, and contribute to their well-being. It aims to simplify the donation process while increasing awareness and community involvement through a user-friendly interface.

## ✨ Features

- Browse orphanages and elderly homes.
- View detailed beneficiary profiles.
- Display beneficiary needs and information.
- Community section showcasing various organizations.
- Responsive and user-friendly interface.
- Firebase integration for storing and retrieving data.
- Easy navigation with modern UI design.

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Harisaran24/Care-Connect.git
```

### 2. Navigate to the Project Directory

```bash
cd Care-Connect
```

### 3. Install Backend Dependencies

```bash
cd backend
npm install
```

### 4. Install Frontend Dependencies

```bash
cd ../client
npm install
```

### 5. Start the Backend Server

```bash
cd ../backend
npm start
```

### 6. Start the React Application

```bash
cd ../client
npm start
```
